# Inteligencia artificial sin artificios — charla

Charla de Samuel Solís para la DrupalCamp Spain 2026, basada en su libro *Inteligencia Artificial sin artificios*.

- `charla-drupalcamp-2026.md`: el guion (discurso, notas y preguntas probables).
- `presentacion/`: la presentación, en HTML, CSS y JavaScript sin dependencias. Se abre con `presentacion/index.html` en el navegador; teclas y detalles en `presentacion/README.md`.
- `CLAUDE.md` / `AGENTS.md`: estado del trabajo, decisiones y cómo verificar los cambios.
